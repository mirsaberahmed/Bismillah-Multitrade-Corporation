# Bismillah Multitrade ERP

A comprehensive and modern Invoice, Billing, Challan/Delivery Slip, Customer Ledger, Inventory, and Finance Management Web Application built with React 19, TypeScript, Vite, and Tailwind CSS.

---

## 🚀 Features

- **Invoice & Billing Management**: Create, view, print, and delete multi-item invoices with automated discount, tax, and currency support (BDT ৳).
- **Delivery Challan System**: Generate delivery slips, track dispatched vs delivered stock, and print professional delivery challans.
- **Customer & Supplier Ledgers**: Complete tracking of balances, receivables, payables, and transaction histories.
- **Inventory & Stock Tracking**: Real-time stock reservation, deduction options, and stock alerts.
- **Finance & Money Receipts**: Cash/bank accounts, expense tracking, and printable money receipts with corporate stamp/seal.
- **Data Export & Import**: Backup and restore data in JSON or Excel formats.
- **Modern Responsive UI**: Built with Tailwind CSS and Lucide icons.

## 🌐 Deploy to Free Hosting Platforms

Once pushed to GitHub, you can publish this app in 1-click on:

### Option 1: Deploy on Vercel (Recommended)
1. Go to [vercel.com](https://vercel.com/) and sign up / log in with your email.
2. Click **Add New** > **Project**.
3. Import your GitHub repository.
4. Framework Preset will automatically detect **Vite**.
5. Click **Deploy**. Your app will be live with a free SSL domain!

### Option 2: Deploy on Netlify
1. Go to [netlify.com](https://www.netlify.com/).
2. Click **Add new site** > **Import an existing project**.
3. Connect your GitHub account and choose this repository.
4. Build command: `npm run build`
5. Publish directory: `dist`
6. Click **Deploy Site**.

### Option 3: Deploy on Render or Cloudflare Pages
- Connect GitHub repo and set Build Command to `npm run build` and Output Directory to `dist`.
